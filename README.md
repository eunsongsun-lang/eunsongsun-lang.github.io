# Diez Office home page: speed test

Static snapshot of the diezoffice.com home page, served twice from the same host so only the theme changes differ:

- `/` (after): lazy-loaded hero images, deferred videos, no preloader, trimmed JS (theme branch `perf/lazy-load-images`)
- `/before/`: the current live theme, unchanged

Photos and videos are loaded from diezoffice.com. Pages are `noindex`; the canonical URL points to the real site.
Project links open the live site. Not a working copy of the website.
